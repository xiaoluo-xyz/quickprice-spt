## 📖 简介

**QuickPrice（快速价格）** 是一个综合性的 SPT 模组，可以在物品栏的提示框中直接显示物品的实时价格。通过颜色编码的价格指示器和详细的市场信息，帮助你做出明智的拾取、出售或保留决策。

### ✨ 核心功能

- 💰 **实时价格显示** - 跳蚤/商人价格展示，禁售物品价格来源可选
- 🎨 **颜色编码系统** - 基于价值的六级颜色分类，支持物品栏背景着色
- 🔫 **武器配件定价** - 计算包含所有配件的总价值并显示明细
- 🛡️ **护甲与穿甲提示** - 护甲等级与子弹穿甲力着色显示
- 📊 **单格价值** - 价值密度与堆叠单价阈值，避免总价偏差
- 🧭 **地面物品价格** - 战局内地面物品名称显示价格与颜色
- 📈 **战局结算追踪** - 带入/损耗/收获/结算统计，支持K单位显示
- 🔊 **搜索音效与耗时** - 六档时长预设，按档开关与自定义音效
- ⚡ **动态价格缓存** - 开仓自动刷新 + 手动刷新热键（F10）
- 🧩 **服务端增强** - 热加载配置、跳蚤黑名单、商人回收价缓存

## 🚀 安装说明

### 前置要求

- SPT (单机塔科夫) **4.0.0**
- BepInEx **5.4.22** 或更高版本（SPT 自带）

### 客户端安装（BepInEx 插件）

1. 从 [Releases](https://github.com/2324834989/quickprice-spt/releases) 下载最新版本
2. 将 `QuickPrice.dll` 解压到：
   ```
   SPT安装目录/BepInEx/plugins/QuickPrice/
   ```
3. 启动 SPT 即可使用！

### 服务端安装（可选 - 用于动态价格）

1. 将服务端模组解压到：
   ```
   SPT安装目录/user/mods/QuickPrice/
   ```
2. 重启 SPT 服务器
3. 在客户端配置中启用"使用动态价格"（按 F12）

更多服务端配置说明见 [QuickPrice.Server.Config.md](QuickPrice.Server.Config.md)。

## 🎮 使用方法

### 基本操作

- **悬停显示价格** - 默认鼠标悬停即显示
- **可选 Ctrl 限制** - 在配置中启用后需按住 `左Ctrl` 或 `右Ctrl`
- **手动刷新价格** - 默认 `F10` 强制刷新动态价格（可改键）

### 颜色编码系统

#### 基于价格的颜色（普通物品）
| 颜色 | 价格区间 | 说明 |
|------|----------|------|
| ⚪ 白色 | ≤ 25,000₽ | 普通物品 |
| 🟢 绿色 | 25,001 - 45,000₽ | 低价值 |
| 🔵 蓝色 | 45,001 - 70,000₽ | 中等价值 |
| 🟣 紫色 | 70,001 - 100,000₽ | 高价值 |
| 🟠 橙色 | 100,001 - 250,000₽ | 极高价值 |
| 🔴 红色 | > 250,000₽ | 超高价值 |

#### 基于穿甲的颜色（子弹和弹匣）
| 颜色 | 穿甲值 | 有效性 |
|------|--------|--------|
| ⚪ 白色 | < 20 | 低穿甲 |
| 🟢 绿色 | 20 - 29 | 轻型护甲 |
| 🔵 蓝色 | 30 - 39 | 中型护甲 |
| 🟣 紫色 | 40 - 49 | 重型护甲 |
| 🟠 橙色 | 50 - 59 | 5级护甲 |
| 🔴 红色 | ≥ 60 | 6级护甲 |

#### 护甲等级颜色
| 颜色 | 护甲等级 | 防护等级 |
|------|----------|----------|
| ⚫ 灰色 | 1级 | 最低防护 |
| 🟢 绿色 | 2级 | 轻型防护 |
| 🔵 蓝色 | 3级 | 中型防护 |
| 🟣 紫色 | 4级 | 重型防护 |
| 🟠 橙色 | 5级 | 极重防护 |
| 🔴 红色 | 6级 | 最高防护 |

### 配置设置

游戏内按 **F12** 打开 BepInEx 配置管理器，可自定义：

- 切换价格显示方式（悬停/按 Ctrl）
- 选择价格来源、禁售物品策略与K单位显示
- 设置搜索音效/耗时与各等级开关
- 调整战局结算显示与非发现物计价
- 缓存模式、自动刷新与手动刷新热键
- 大容器性能调优

## ⚙️ 配置选项

### 价格显示
- **启用插件** - 总开关
- **显示跳蚤/商人价格** - 分别开关价格来源
- **非发现物隐藏跳蚤价** - 可选隐藏非FIR跳蚤价
- **禁售物品价格来源** - Default / 跳蚤 / 商人
- **显示跳蚤税费** - 上架费用与净利润
- **最佳价格加粗** - 突出显示最高价格行
- **显示每格价格** - 价值密度计算
- **显示武器配件价格** - 包含配件并可显示明细
- **启用K单位显示** - ≥ 10,000 显示为 ₽10k
- **堆叠单价阈值** - 堆叠过大时仅显示单价

### 提示与交互
- **按住Ctrl键才显示** - 可选
- **提示框延迟（秒）** - 0–2秒
- **取消提示框宽度限制** - 避免自动换行
- **显示提示框下划线** - 物品名下方分隔线

### 颜色与地面显示
- **启用颜色编码** - 价格/穿甲着色
- **子弹按穿甲等级着色** - 使用穿甲阈值
- **物品名称着色** - 提示框名称颜色
- **自动着色物品背景** - 物品栏格子着色（实验性）
- **地面物品显示价格** - 战局内地面名称显示（需启用名称着色）
- **护甲等级着色** - 护甲等级颜色与文字
- **阈值重置按钮** - 在 F12 配置管理器中重置价格/穿甲阈值

### 价格缓存与刷新
- **使用动态价格** - 从服务端获取跳蚤价
- **价格缓存模式** - 永久 / 5分钟 / 10分钟 / 手动
- **打开物品栏自动刷新** - 过期时后台刷新
- **刷新价格快捷键** - 默认 `F10`

### 战局结算
- **战局内显示带入/损耗** - 控制叠层显示
- **排除项目** - 保险箱/刀具/臂带/狗牌/特殊栏位
- **非发现物使用商人回收价** - 结算计价策略
- **战局结算K单位显示** - 结算数值简写
- **耐久损耗计入** - 武器/护甲耐久与维修系数

### 搜索设置
- **启用搜索音效** - 按价值等级播放（1-6档）
- **按档音效开关** - 可关闭指定等级
- **启用搜索时间调整** - 按等级覆盖搜索耗时
- **随机延迟** - 最小/最大随机值
- **各等级时间** - 1-6档时长预设

### 调试
- **客户端日志开关** - 控制 Debug/Warn 输出

## 🛠️ 从源码构建

### 客户端（BepInEx 插件）

```bash
cd Sources/Client
dotnet build -c Release
```

输出：`bin/Release/net471/QuickPrice.dll`

### 服务端（SPT 模组）

```bash
cd Sources/Server
```

- .NET Framework 4.7.1 SDK（客户端）
- .NET 9.0 SDK（服务端）
- SPT 4.0.0 程序集（参考 .csproj 中的路径）

## 📊 性能优化

QuickPrice 包含智能性能优化：

- **智能容器计算** - 限制递归深度和物品数量（可关闭）
- **异步价格加载** - 非阻塞的后台更新
- **高效缓存** - 可配置的缓存过期时间
- **大容器跳过** - 避免超过阈值的大型物品箱卡顿

默认限制（推荐）：
- 最大递归深度：**10 层**
- 单容器最大物品数：**100 个**
- 大容器阈值：**50 个**

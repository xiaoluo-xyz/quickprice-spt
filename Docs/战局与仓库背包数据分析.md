# 战局/仓库背包与装备数据路径梳理（基于现有反射/补丁代码）

## 范围与说明
- 本文档基于当前仓库已有的反射/补丁点整理“已确认”的数据路径。
- 另外补充了基于 `Assembly-CSharp.dll` 反射确认的玩家/装备入口（来自 `Sources/Client/bin/Release/net471/Assembly-CSharp.dll`）。

## 已确认的数据入口（可直接复用）

### 1) 战局内交互物品（地面/容器交互）
- 入口链路：`ActionPanel -> GamePlayerOwner -> Player.InteractableObject -> LootItem -> LootItem.Item`。
- 该链路已用于地面物品名称着色，可复用为战局内“当前交互物品”的数据入口。
- 代码参考：`Sources/Client/Patches/LootItemLabelPatch.cs:171`、`Sources/Client/Patches/LootItemLabelPatch.cs:180`。

### 2) 仓库/物品栏 UI 入口
- 物品栏打开入口：`InventoryScreen.Show()`（可作为“仓库/物品栏已打开”的触发点）。
- UI 格子上的物品实例：`GridItemView.Item`，在鼠标进入时直接拿到 `Item`。
- 代码参考：`Sources/Client/Patches/InventoryScreenShowPatch.cs:22`、`Sources/Client/Patches/ItemHoverPatches.cs:24`。

### 3) 战局内玩家穿戴信息（装备槽）
- 战局玩家入口：`EFT.GameWorld.MainPlayer`（本地玩家），或 `EFT.GameWorld.AllAlivePlayersList`（所有存活玩家）。
- 玩家装备入口：`EFT.Player.Equipment`（类型 `EFT.InventoryLogic.InventoryEquipment`），等价于 `EFT.Player.Inventory.Equipment`。
- 槽位获取：`InventoryEquipment.GetSlot(EquipmentSlot slotName)` 或遍历 `InventoryEquipment.AllSlots`。
- 槽位物品：`Slot.ContainedItem` 即“玩家当前穿戴/携带在该槽位上的物品”。  
- 装备槽枚举：`EquipmentSlot`（见下方列表）。

**EquipmentSlot 枚举值（已确认）**：
`FirstPrimaryWeapon` / `SecondPrimaryWeapon` / `Holster` / `Scabbard` / `Backpack` / `SecuredContainer` / `TacticalVest` / `ArmorVest` / `Pockets` / `Eyewear` / `FaceCover` / `Headwear` / `Earpiece` / `Dogtag` / `ArmBand`

**最小示例（伪代码）**：
```
var gw = Singleton<GameWorld>.Instance; // 常用入口
foreach (var p in gw.AllAlivePlayersList)
{
    var equip = p.Equipment;
    var headwear = equip.GetSlot(EquipmentSlot.Headwear)?.ContainedItem;
    var armor = equip.GetSlot(EquipmentSlot.ArmorVest)?.ContainedItem;
}
```

### 4) 物品归属（是否属于装备树）
- 使用 `Item.Parent.GetOwner().RootItem is InventoryEquipment` 判断当前物品是否属于装备树。
- 代码参考：`Sources/Client/Patches/SearchPatch.cs:158`。

### 5) 背包/容器数据（内容物）
- 容器判定：优先读取 `IsContainer` 属性；备用方式是检测 `Grids` 是否存在/非空。
- 容器内容：`Grids -> Items`，每个 `Item` 仍可继续递归。
- 兼容属性名变化：`Grids / Grid / Containers / Container`（反射尝试多个名字）。
- 代码参考：
  - `Sources/Client/Patches/TestTooltipPatch.cs:1818`
  - `Sources/Client/Patches/TestTooltipPatch.cs:1774`
  - `Sources/Client/Patches/TestTooltipPatch.cs:2056`

### 6) 装备槽/配件槽（武器与配件树）
- 配件槽：`Mod.Slots`，每个 slot 内通过 `slot.ContainedItem` 取子配件。
- 适用于武器与配件树的递归遍历。
- 代码参考：`Sources/Client/Services/PriceCalculator.cs:159`。

### 7) 护甲/插板槽（护甲内部槽位）
- 护甲内部槽位：`AllSlots -> slot.ContainedItem`（含插板/内衬）。
- 代码参考：`Sources/Client/Utils/ArmorHelper.cs:101`、`Sources/Client/Utils/ArmorHelper.cs:118`。

### 8) 快速枚举第一层物品
- `Item.GetFirstLevelItems()` 可直接拿到容器第一层物品。
- 代码参考：`Sources/Client/Patches/SearchPatch.cs:208`。

## 数据结构示意（从 Item 出发）
- 装备/配件树：`Weapon.Mods` 或 `Mod.Slots -> slot.ContainedItem -> Mod (递归)`。
- 背包/容器树：`Item (IsContainer/Grids) -> Grid.Items -> Item (递归)`。
- 护甲插板：`Item.AllSlots -> slot.ContainedItem -> ArmorPlateItemClass`。
